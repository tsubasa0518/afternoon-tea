## 実装範囲

- extraction.py：標準ライブラリのDOM読取。一休のプラン詳細、食べログcourse-dtl、TableCheck menu-itemを個別処理する。
- プラン名、メニュー、予約導線の公開文言、明示された提供期間、通常税サ込価格、利用曜日・時間、スイーツを項目別に原文・URL・確認日と記録する。営業時間や予約受付期間は提供情報に転用しない。
- 税抜価格、税のみ明記してサービス料不明の価格、割引との区別がつかない価格はnull。年不明の期間もnull。期間が明示されないことを無期限提供と解釈しない。
- 店名の正規化後の一致に加え、施設/ラウンジと駅の根拠を照合する。ホテル内の別ラウンジを名前の類似だけで統合しない。
- apply_pageはHTMLを再抽出し、同一性・ジャンル・プラン本文・メニュー・予約導線・一休の食事帯を確認できる場合だけ既存JSONに反映する。未確認値に出典を生成しない。
- 同一プランを重複排除し、テーマ・期間・価格・曜日・時間・メニューが異なるものを分ける。
- extraction_runは匿名GETで取得、ページ単位でチェックポイント保存、JSON検証、既存生成器によるHTML生成までを.staging内で行う。

```sh
python3 -m afternoon_tea.extraction_run --pilot --limit 5 --seconds 120
python3 -m afternoon_tea.extraction_run --limit 14 --seconds 180
python3 -m unittest discover -s tests -q
```
