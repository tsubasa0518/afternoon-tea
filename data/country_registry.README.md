# 国・地域コード検証データ

`country_registry.json` はテーマ判定の国別ルール表ではありません。全ISO 3166-1 alpha-2割当（249国・地域）についてコードと標準国名を照合する、生成済みの軽量な参照データです。香港等の地域も含みます。対応国の事前選定・毎週の登録・ネット取得は不要です。

この開発時に、端末内 `/usr/share/zoneinfo.default/iso3166.tab` のIANA tzdb資料（2025-07-01注記、ISO/TC 46 N1127 2024-02-29参照、public domain）からコードと英語名を読み、既存Nodeランタイムの `Intl.DisplayNames(['ja'/'en'], {type:'region'})` が持つUnicode CLDR名を組み合わせて生成しました。ICU/CLDRバージョンはJSONに記録しています。開発時も追加HTTPアクセスを行っていません。

週次実行・CI・HTML生成はPython標準ライブラリでこのJSONを読むだけです。コード割当の公式更新が必要な場合に開発変更として再生成します。独自の予約済みコード（UK等）や未割当コード（ZZ等）はISO国コードとして受け付けません。国名は日本語標準名・英語CLDR名・IANA資料名との一致を検証します。

テーマの意味判断はClaudeが取得済みの各プランの内容から行います。`country_themes prepare` が新規・変更分だけを提示し、`finalize` が検証・内部根拠記録・ハッシュ保存を行います。未知という判断も再利用します。価格やチェック日時から国を判断したり、メニューを追加で取得したりしません。
